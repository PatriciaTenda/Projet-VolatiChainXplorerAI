# Organisation de la veille

Les synthèses de veille sont centralisées dans le dépôt du projet sous forme de fichiers Markdown. 
Les fiches détaillées, le tableau de suivi des sources et les preuves de collecte sont organisés dans une arborescence dédiée afin de garantir la traçabilité et de faciliter leur consultation et leur mise à jour.

## Arborescence du dossier veille

````
docs/veille/
├── fiches/
├── publications/
├── preuves/
├── synthese_veille.md
├── tableau_veille.csv
└── README.md 
````
